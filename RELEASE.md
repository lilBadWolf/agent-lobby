# Release Notes

🚀 **Release highlights for agent-lobby 0.7.0**

- 🔐 **Web lobby chat works with encryption again** so web users can read and send lobby messages alongside desktop users. If a client can't decrypt the lobby, it now tells you why instead of silently dropping messages.
- 👻 **No more ghost users** — people who crash or lose connection drop off the online list automatically, and leaving a lobby always clears you out.
- ♟️ **Chess got serious** with under-promotion (pick queen, rook, bishop or knight), a RESIGN button, draws by insufficient material, a session score, and correct captured-piece trays.
- 🔁 **Fair rematches in Chess and Tic Tac Toe** — rematches are now requested and accepted between games (no more wiping a game in progress), and colors/first move alternate each round.
- ❌⭕ **Tic Tac Toe shows who won**, highlights whose turn it is, and keeps a running score.
- 🚢 **Battleship turn fixes** so a slow connection can no longer give both players the turn or let a shot fire twice.
- 🏓 **Pong plays nicer** — arrow keys no longer hijack the chat box, holding both arrows works smoothly, and the game stops cleanly if the link drops.
- 👀 **Group DM spectators see the real match** for every game, live, instead of a separate copy of the board.
- 📡 **Disconnects are handled** in every game with a clear "link lost" state instead of a frozen board.

> A big games-and-stability update across desktop and web 💚🛰️🐺
